# Pavo AI Prompts

A small collection of prompts and settings I use for AI video generation on [Pavo AI](https://pavoai.app).

- Site: **https://pavoai.app**
- Prompt gallery: <https://pavoai.app/prompts>

## Text-to-video: product shot

```
A matte ceramic cup rotating slowly on a dark stone surface,
soft window light from the left, shallow depth of field,
35mm, gentle camera push-in, 6 seconds.
```

Camera: slow push-in · Motion: 3/10 · Duration: 6s · Aspect: 16:9

## Image-to-video: character consistency

Feed the same reference frame for every shot, keep the seed, and only change the action line:

```
Same character, same wardrobe, walking through a narrow alley,
overcast light, handheld feel, 5 seconds.
```

## Shorts hook (first 2 seconds)

```
Extreme close-up on hands opening a box, warm rim light,
fast snap zoom out revealing the product, 4 seconds.
```

## Dubbing pass

Lock the cut first, then dub. Re-check lip-sync on any shot where the mouth is visible for more than one second.
